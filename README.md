# Typing Trainer

A comprehensive typing trainer with multiple modes to improve your typing speed and accuracy.

## Features

- **Practice Mode**: Type text passages with real-time WPM and accuracy tracking
- **Game Mode**: Falling words typing game with scoring and lives
- **Focus Timer**: Pomodoro-style timer for productivity sessions
- **Profile System**: Customizable username and avatar
- **High Score Tracking**: Save your best scores across all modes

## Live Demo

Visit: `https://[your-username].github.io/Typing-Trainer/`

## Usage

Simply open `index.html` in any modern web browser. No installation or server required!

## Technologies

- React 18
- Tailwind CSS
- localStorage for data persistence
